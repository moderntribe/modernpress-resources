# Plugins

A collection of plugins and core plugin resources for the Moose / ModernPress framework.

## Guidelines

1. Plugin resources should be created in their own directory with a descriptive name.
1. Resource directories should utilize the provided `README-sample.md` file in the root directory.
1. Link to the resource README file below!
1. Resources should follow the version naming scheme of `0.1-alpha` for in progress work, `1.0-beta` for complete resources that may need polishing, and `>1.0` for stable versions.
